# 斩鬼夜行 · 鬼灭之刃粉丝同人小游戏

一款在浏览器里就能玩的横版斩鬼动作游戏。扮演鬼杀队剑士，在月夜下用**水之呼吸**斩杀来袭的恶鬼，共 **8 关**，从杂鱼鬼一路杀到「上弦之鬼」，难度递增。

🎮 **在线游玩**：https://chengeys.github.io/demon-slayer-night-hunt/

## 玩法

| 按键 | 操作 |
|---|---|
| A / D 或 ← / → | 移动 |
| W / ↑ / 空格 | 跳跃（可二段跳）|
| J / Z | 挥刀（连按打出三连斩）|
| Shift | 闪避突进（短暂无敌）|
| K / X | 水之呼吸 · 贰之型「水车」（旋转大范围斩）|
| L / C | 水之呼吸 · 壹之型「水面斩击」（突进斩）|
| U / V | 水之呼吸 · 叁之型「流流舞·水刃」（远程三连）|
| P / M / F | 暂停 / 静音 / 全屏 |

手机上有触屏按钮（跳/斩/闪避/水车/水面/水刃），横屏竖屏都会显示；右上角 ⛶ 可进全屏游玩。

## 关卡（8 关，难度递增）

| 关卡 | 出没恶鬼 |
|---|---|
| 第壹关 · 狭雾山试炼 | 小鬼 |
| 第贰关 · 浅草夜行 | 小鬼、疾鬼 |
| 第叁关 · 那田蜘蛛山 | 疾鬼、蛛丝鬼（远程吐丝）|
| 第肆关 · 无限列车 | 巨鬼、疾鬼、蛛丝鬼 |
| 第伍关 · 吉原花街 | 下弦精英鬼、巨鬼 |
| 第陆关 · 刀匠之村 | 下弦精英鬼 ×2、巨鬼 |
| 第柒关 · 柱之试炼 | 下弦精英鬼 ×3、蛛丝鬼、巨鬼 |
| 最终决战 · 上弦之鬼 | Boss：爪击三连、高速突进、扇形丝牢弹幕、召唤小鬼，残血狂暴 |

越往后的鬼血量/速度/伤害越高、前摇越短，祝武运昌隆！

## 技术

- 纯 HTML5 Canvas + 原生 JavaScript，无外部资源、无构建步骤
- WebAudio 实时合成音效（挥刀、命中、水之呼吸等）
- 直接用 GitHub Pages 免费托管

## 本地运行

```bash
# 任意静态服务器，例如：
npx serve .
# 或
python3 -m http.server 8000
```

然后浏览器打开 http://localhost:8000 即可。
